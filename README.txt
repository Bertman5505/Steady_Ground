Steady Ground - installable Android web app (PWA)

Files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png
Upload all files together to the root of any static host that serves HTTPS
(GitHub Pages, Cloudflare Pages, Netlify). Then open the URL in Chrome on
Android and choose "Add to home screen" / "Install app".
Entries are stored on the phone only (browser localStorage).
